# Dynamic Closure Notebook — Entry 12
## Alternative Structure Controls and Premise Audit

### Scientific status

Entry 12 does not add a new EDF mechanism.

It revisits the structural alternatives first explored before DCT was formally
consolidated and asks a stricter question:

> What must be changed in the DCT premise chain before a count other than
> \(k^2\) can describe fundamental dynamic closure?

The answer is not obtained by arithmetic preference alone.

Instead, each candidate is interpreted as a concrete operator/relation space and
tested against the completed DCT requirements.

---

# 1. DCT structural baseline

The relevant premises are:

### P1 — finite cyclic phase resolution

\[
A_k
=
\left\{
e^{2\pi i m/k}
:
m\in\mathbb Z_k
\right\}
\]

is resolved, giving the phase operator

\[
Z|m\rangle
=
\omega_k^m|m\rangle.
\]

### P2 — coherent primitive phase evolution

Primitive evolution advances phase coherently.

### P3 — primitive transitive traversal

Primitive recurrence implies a traversal generator

\[
U_r=X^r,
\qquad
\gcd(r,k)=1,
\]

and therefore

\[
X\in\operatorname{alg}(U_r).
\]

### P4 — unital associative dynamic closure

The fundamental closure object is the smallest unital associative complex
operator algebra containing all operations required by P1–P3.

### P5 — Fibonacci compatibility

\[
F_k=C(k).
\]

Entries 05–08 established

\[
\boxed{
P1+P2+P3+P4
\Rightarrow
\operatorname{alg}(Z,X)=M_k(\mathbb C)
}
\]

and therefore

\[
\boxed{
C(k)=k^2.
}
\]

Entry 12 tests whether the familiar alternative counts can replace this result
without changing those premises.

---

# 2. Candidate structural counts

The controls are

\[
C_1(k)=k^2,
\]

\[
C_2(k)=k^2-1,
\]

\[
C_3(k)=k(k-1),
\]

\[
C_4(k)=\frac{k(k+1)}2,
\]

\[
C_5(k)=\frac{k(k-1)}2,
\]

and

\[
C_6(k)=k.
\]

These counts correspond naturally to:

1. complete ordered relations including self-relations;
2. traceless/normalized-state coordinates;
3. ordered relations with diagonal self-relations deleted;
4. unordered symmetric relations including self-relations;
5. unordered symmetric relations without self-relations;
6. a single cyclic generator.

The question is whether any of these smaller structures remains a valid
fundamental closure under P1–P4.

---

# 3. Control A — full ordered/self relation space

The matrix-unit basis

\[
E_{ij}=|i\rangle\langle j|,
\qquad
i,j=1,\ldots,k
\]

contains

\[
k^2
\]

elements.

It includes the identity,

\[
I=\sum_iE_{ii},
\]

and is closed under multiplication:

\[
E_{ij}E_{\ell m}
=
\delta_{j\ell}E_{im}.
\]

Therefore

\[
\boxed{
\operatorname{span}\{E_{ij}\}
=
M_k(\mathbb C).
}
\]

This candidate satisfies P4 exactly.

Its Fibonacci compatibility equation is

\[
F_k=k^2.
\]

The finite scan through \(k=500\) gives

\[
k=12,
\]

and the Bugeaud–Mignotte–Siksek perfect-power theorem supplies the global
arithmetic uniqueness already used in Entry 08.

---

# 4. Control B — traceless space \(k^2-1\)

The traceless subspace

\[
\mathfrak{sl}_k
=
\{
A\in M_k(\mathbb C):
\operatorname{Tr}A=0
\}
\]

has complex dimension

\[
k^2-1.
\]

Both DCT generators can individually lie in this space for \(k>1\):

\[
\operatorname{Tr}Z=0,
\]

and the cyclic shift satisfies

\[
\operatorname{Tr}X=0.
\]

So the failure is not P1 or P3 individually.

The failure is P4.

Take

\[
A=E_{11}-E_{22}.
\]

Then

\[
\operatorname{Tr}A=0,
\]

but

\[
A^2=E_{11}+E_{22},
\]

which has nonzero trace.

Therefore

\[
\boxed{
\mathfrak{sl}_k
\text{ is not closed under ordinary matrix multiplication.}
}
\]

It also excludes the identity.

Once unital closure is restored,

\[
M_k(\mathbb C)
=
\mathfrak{sl}_k
\oplus
\mathbb C I,
\]

so the dimension returns to

\[
\boxed{k^2}.
\]

Thus

\[
k^2-1
\]

is a valid reduced coordinate count, but not the full unital associative
dynamic closure count.

The Fibonacci equation

\[
F_k=k^2-1
\]

has no solution in the finite scan \(2\le k\le500\).

---

# 5. Control C — ordered relations without self-relations

Consider

\[
\mathcal O_k
=
\operatorname{span}
\{
E_{ij}:i\ne j
\}.
\]

Its dimension is

\[
k(k-1).
\]

The traversal operator \(X\) lies in this off-diagonal space for \(k>1\), so
P3 can survive.

However, the phase operator \(Z\) is diagonal, so P1 cannot be represented
inside this restricted relation space.

More decisively, P4 fails because

\[
\boxed{
E_{ij}E_{ji}=E_{ii}.
}
\]

Therefore deleted self-relations are regenerated by ordinary composition.

Once the diagonal matrix units are admitted, all \(E_{ij}\) are present and

\[
\boxed{
\operatorname{alg}(\mathcal O_k)
=
M_k(\mathbb C).
}
\]

Hence the full closure dimension again becomes

\[
k^2.
\]

The equation

\[
F_k=k(k-1)
\]

has no solution in the scan through \(k=500\).

---

# 6. Control D — unordered relations including self-relations

The complex symmetric relation space has basis

\[
E_{ii},
\]

together with

\[
S_{ij}=E_{ij}+E_{ji},
\qquad
i<j.
\]

Its dimension is

\[
\frac{k(k+1)}2.
\]

The phase operator \(Z\) is diagonal and therefore belongs to this space.

But a generic cyclic shift \(X\) is directed and nonsymmetric for \(k>2\), so
P3 is not represented faithfully.

P4 also fails.

For example,

\[
E_{ii}S_{ij}
=
E_{ij}.
\]

The product is a directed matrix unit and is not symmetric.

Therefore

\[
\boxed{
\text{symmetric matrices are not closed under generic matrix multiplication.}
}
\]

Moreover, once \(E_{ij}\) and \(E_{ji}\) are individually regenerated, the
complete matrix-unit basis follows.

Thus

\[
\boxed{
\operatorname{alg}
\left(
\text{symmetric relation space}
\right)
=
M_k(\mathbb C).
}
\]

The Fibonacci control gives

\[
F_{10}=55
=
\frac{10\cdot11}{2}.
\]

So this alternative selects

\[
\boxed{k=10}
\]

in the finite scan.

That is useful rather than problematic: it demonstrates that Fibonacci
compatibility alone does not select 12. The result depends on the underlying
relation topology.

# 7. Control E — unordered relations without self-relations

Now retain only

\[
S_{ij}=E_{ij}+E_{ji},
\qquad
i<j.
\]

The dimension is

\[
\frac{k(k-1)}2.
\]

This structure excludes the diagonal phase operator \(Z\), so P1 fails.

It also identifies opposite traversal directions, so generic P3 fails.

P4 fails immediately:

\[
\boxed{
S_{ij}^2
=
E_{ii}+E_{jj}.
}
\]

Thus self-relations reappear under multiplication.

For \(k\ge3\), take three distinct indices \(i,j,\ell\). Then

\[
S_{ij}^2
+
S_{i\ell}^2
-
S_{j\ell}^2
=
2E_{ii}.
\]

Therefore the diagonal matrix unit is generated:

\[
E_{ii}
=
\frac12
\left(
S_{ij}^2
+
S_{i\ell}^2
-
S_{j\ell}^2
\right).
\]

Then

\[
E_{ii}S_{ij}=E_{ij}.
\]

Hence all directed matrix units are generated and

\[
\boxed{
\operatorname{alg}\{S_{ij}\}
=
M_k(\mathbb C),
\qquad
k\ge3.
}
\]

The special case \(k=2\) is degenerate: the only symmetric off-diagonal
generator is \(S_{12}\), and its unital algebra has dimension 2.

The Fibonacci equation

\[
F_k=\frac{k(k-1)}2
\]

selects only the low-order solution

\[
\boxed{k=2}
\]

in the finite scan.

# 8. Control F — single-generator cyclic space

A \(k\)-dimensional cyclic algebra can be perfectly legitimate if only one
generator is retained.

For phase only,

\[
\mathcal A_Z
=
\operatorname{span}
\{
I,Z,Z^2,\ldots,Z^{k-1}
\},
\]

with

\[
\dim\mathcal A_Z=k.
\]

This algebra is unital and multiplicatively closed.

But it contains no sector traversal generator \(X\), so it fails P3.

Likewise,

\[
\mathcal A_X
=
\operatorname{span}
\{
I,X,X^2,\ldots,X^{k-1}
\}
\]

has dimension \(k\) and is closed, but omits the resolved phase generator
\(Z\), so it fails P1.

The crucial result is therefore:

\[
\boxed{
k
\text{ is a valid one-generator subalgebra dimension,}
}
\]

but not the dimension of the DCT closure containing both required generators.

Once both are restored,

\[
ZX=\omega_kXZ,
\]

and the Weyl family

\[
\{
X^aZ^b
:
(a,b)\in\mathbb Z_k^2
\}
\]

has rank

\[
\boxed{k^2}.
\]

The Fibonacci equation

\[
F_k=k
\]

selects

\[
\boxed{k=5}
\]

in the finite scan.

Again, this is a control demonstrating that a different primitive structure
produces a different Fibonacci closure.

# 11. Premise-level interpretation

The alternatives fail for different reasons.

### \(k^2-1\)

Preserves the individual phase and traversal generators but fails P4 because
the traceless space is not a unital associative algebra under multiplication.

### \(k(k-1)\)

Can retain traversal, but excludes the diagonal phase/self sector and fails P4
because composition regenerates it.

### \(k(k+1)/2\)

Can retain diagonal phase information but loses directed traversal and fails
P4 under noncommuting composition.

### \(k(k-1)/2\)

Loses both the phase diagonal and directed traversal and also fails P4.

### \(k\)

Can satisfy P4 as a genuine one-generator cyclic subalgebra, but only by
dropping either P1 or P3.

Therefore no candidate count smaller than \(k^2\) preserves all of P1–P4.

# 12. Alternative-Structure Control Theorem

## Proposition

Let \(k\ge2\), and assume the DCT requirements P1–P4.

Then any candidate closure space that:

1. contains the resolved phase generator \(Z\);
2. contains a primitive traversal generator \(X\) or \(U_r\);
3. contains the identity;
4. is closed under ordinary complex-linear combination and operator
   multiplication;

must contain the Weyl family

\[
X^aZ^b,
\qquad
a,b\in\mathbb Z_k.
\]

Because these \(k^2\) operators are linearly independent,

\[
\dim\mathcal A\ge k^2.
\]

Since

\[
\mathcal A\subseteq M_k(\mathbb C),
\]

and

\[
\dim M_k(\mathbb C)=k^2,
\]

it follows that

\[
\boxed{
\mathcal A=M_k(\mathbb C)
}
\]

and

\[
\boxed{
\dim\mathcal A=k^2.
}
\]

Therefore every smaller candidate count necessarily changes at least one DCT
premise.

# 14. Falsification status

Entry 12 would be invalidated or require revision if EDF were shown to require
one of the following instead:

- only a single generator rather than both \(Z\) and \(X\);
- an unordered relation structure rather than directed operator composition;
- a nonunital closure;
- a nonassociative composition law;
- a projected state-coordinate manifold rather than the full dynamic operator
  algebra.

Those are genuine alternative theories.

They are not alternative representations of the same DCT assumptions.
