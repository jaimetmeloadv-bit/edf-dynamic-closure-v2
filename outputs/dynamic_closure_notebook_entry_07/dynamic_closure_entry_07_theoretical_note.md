# Dynamic Closure Notebook — Entry 07
## Primitive EDF Phase Evolution and the Traversal Theorem

### Scientific role

Entries 05 and 06 established that a resolved cyclic phase operator together with a cyclic traversal operator generates the finite Weyl algebra and therefore a complete operator space of dimension \(k^2\).

Entry 07 supplies the last internal bridge needed before theorem consolidation:

> derive the traversal operator from the primitive EDF phase evolution itself.

The result below does not use Fibonacci arithmetic, does not assume \(k=12\), and does not begin by postulating a shift matrix.

---

# 1. Primitive coherent phase evolution

Let \(\tau_*\) denote one primitive EDF timing interval and let \(\Omega_*\) denote the coherent phase rate associated with that update.

Sampling the phase at successive timing steps gives the minimal homogeneous recurrence law

\[
\boxed{
\phi_{n+1}
=
\phi_n+\Delta\phi
\pmod{2\pi}
}
\]

with

\[
\Delta\phi=\Omega_*\tau_*.
\]

This is the finite-step form of uniform phase accumulation.

The \(k\)-sector EDF phase kernel is

\[
A_k
=
\left\{
\exp\!\left[i\left(\phi_0+\frac{2\pi m}{k}\right)\right]
:
m\in\mathbb Z_k
\right\}.
\]

Equivalently, with

\[
\omega_k=e^{2\pi i/k},
\]

we may write

\[
A_k=e^{i\phi_0}\{1,\omega_k,\omega_k^2,\ldots,\omega_k^{k-1}\}.
\]

---

# 2. Kernel-preservation lemma

Consider the homogeneous phase update

\[
R_{\Delta\phi}:z\mapsto e^{i\Delta\phi}z.
\]

We require exact preservation of the finite phase kernel:

\[
R_{\Delta\phi}(A_k)=A_k.
\]

Because \(e^{i\phi_0}\in A_k\), preservation requires

\[
e^{i\Delta\phi}e^{i\phi_0}
\in A_k.
\]

Therefore there exists some

\[
r\in\mathbb Z_k
\]

such that

\[
e^{i\Delta\phi}=\omega_k^r.
\]

Hence

\[
\boxed{
\Delta\phi
=
\frac{2\pi r}{k}
\pmod{2\pi}.
}
\]

Conversely, every increment of this form permutes the elements of \(A_k\), so the condition is both necessary and sufficient.

### Kernel-Preservation Lemma

A homogeneous phase increment preserves the finite \(k\)-sector phase kernel exactly if and only if

\[
\boxed{
\Delta\phi=\frac{2\pi r}{k}\pmod{2\pi}
}
\]

for some \(r\in\mathbb Z_k\).

---

# 3. Induced evolution on sector labels

Label the phase sectors by

\[
m\in\mathbb Z_k.
\]

For the allowed increment

\[
\Delta\phi=\frac{2\pi r}{k},
\]

the phase update gives

\[
\phi_m
\mapsto
\phi_m+\frac{2\pi r}{k}
=
\phi_{m+r}.
\]

Therefore the induced map on the sector labels is

\[
\boxed{
m\mapsto m+r\pmod{k}.
}
\]

Let the canonical cyclic shift be

\[
X|m\rangle=|m+1\pmod{k}\rangle.
\]

Then the \(r\)-step update is exactly

\[
\boxed{
U_r=X^r.
}
\]

Thus the shift structure is not inserted after the phase dynamics. It is the matrix representation of the phase-kernel permutation induced by a kernel-preserving primitive phase increment.

---

# 4. Primitive recurrence and full traversal

The additive orbit generated by \(r\) is

\[
0,
r,
2r,
3r,
\ldots
\pmod{k}.
\]

The first positive integer \(n\) for which the orbit returns to the initial sector satisfies

\[
nr\equiv0\pmod{k}.
\]

Its minimal solution is

\[
\boxed{
L(k,r)=\frac{k}{\gcd(k,r)}.
}
\]

The permutation therefore splits into

\[
\boxed{
\gcd(k,r)
}
\]

disjoint cycles, each of length

\[
\frac{k}{\gcd(k,r)}.
\]

Now impose the physically relevant primitive-closure condition:

> the stated \(k\)-sector cycle is primitive, meaning that its first recurrence occurs only after \(k\) updates.

That is,

\[
L(k,r)=k.
\]

Using the orbit-length formula,

\[
\frac{k}{\gcd(k,r)}=k,
\]

which implies

\[
\boxed{
\gcd(k,r)=1.
}
\]

Hence the orbit contains all \(k\) sectors before returning.

This is important logically:

\[
\boxed{
\text{full traversal is derived from primitive recurrence; it is not separately assumed.}
}
\]

If \(\gcd(k,r)>1\), the evolution closes prematurely on a smaller subcycle, so the true primitive recurrence order is less than \(k\).

---

# 5. Primitive Traversal Theorem

### Theorem

Let a finite EDF phase kernel contain \(k\) equally spaced phase sectors. Suppose:

1. phase evolution is homogeneous from one primitive timing update to the next,
   \[
   \phi_{n+1}=\phi_n+\Delta\phi\pmod{2\pi};
   \]
2. the evolution preserves the finite phase kernel exactly;
3. \(k\) is the primitive recurrence order, so there is no return to the initial phase sector before the \(k\)-th update.

Then there exists an integer \(r\) satisfying

\[
\gcd(k,r)=1
\]

such that the induced sector evolution is

\[
\boxed{
U_r=X^r.
}
\]

Consequently, the evolution traverses every one of the \(k\) sectors exactly once before recurrence.

### Proof

Kernel preservation implies

\[
\Delta\phi=2\pi r/k
\]

for some \(r\in\mathbb Z_k\). Therefore the induced sector map is

\[
m\mapsto m+r\pmod{k},
\]

represented by \(X^r\).

The recurrence order is

\[
k/\gcd(k,r).
\]

Primitive recurrence at exactly \(k\) steps therefore requires

\[
\gcd(k,r)=1.
\]

Thus the orbit has length \(k\) and visits every sector before returning.

\[
\boxed{\mathrm{QED}}
\]

---

# 6. Equivalence to the canonical shift

When

\[
\gcd(k,r)=1,
\]

multiplication by \(r\) is a permutation of \(\mathbb Z_k\).

Define

\[
P_r|m\rangle
=
|rm\pmod{k}\rangle.
\]

Then

\[
P_r^\dagger X^rP_r|m\rangle
=
|m+1\rangle.
\]

Therefore

\[
\boxed{
P_r^\dagger X^rP_r=X.
}
\]

Every homogeneous primitive traversal is therefore unitarily equivalent, by a relabeling of the cyclic sectors, to the canonical one-step shift.

This gives the strongest form of the result needed by Entry 06:

\[
\boxed{
\text{primitive EDF phase recurrence}
\Longrightarrow
X\text{ up to cyclic relabeling}.
}
\]

---

# 7. Euler-totient structure

The admissible full-cycle step indices are precisely the units of the residue ring

\[
\mathbb Z_k.
\]

Their number is Euler's totient function

\[
\boxed{
\varphi(k)
=
\#\{r:1\le r<k,\ \gcd(k,r)=1\}.
}
\]

Thus a \(k\)-sector primitive phase kernel generally admits several orientation/orderings of the same complete cyclic traversal.

They are not distinct closure dimensions; they are distinct generators of the same cyclic group, all conjugate to the canonical shift under sector relabeling.

---

# 8. The special diagnostic case k = 12

For

\[
k=12,
\]

the full-cycle step indices are

\[
\boxed{
r\in\{1,5,7,11\}.
}
\]

Indeed,

\[
\gcd(12,r)=1
\]

only for these four nonzero residues.

Therefore

\[
\varphi(12)=4.
\]

All four updates

\[
X,
\quad X^5,
\quad X^7,
\quad X^{11}
\]

visit all twelve sectors before recurrence and are relabeling-equivalent to \(X\).

By contrast:

\[
r=2
\Rightarrow
\gcd(12,2)=2
\Rightarrow
2\text{ cycles of length }6,
\]

\[
r=3
\Rightarrow
3\text{ cycles of length }4,
\]

\[
r=4
\Rightarrow
4\text{ cycles of length }3,
\]

and

\[
r=6
\Rightarrow
6\text{ cycles of length }2.
\]

These are premature closures and therefore cannot represent a primitive 12-sector recurrence.

The appearance of \(12\) in this diagnostic section is downstream of the earlier arithmetic closure result; none of the Entry 07 theorem depends on \(12\).

# 10. Literature correspondence

The mathematical structure used here is standard and independently established.

Finite-dimensional phase formalisms use equally spaced phase states related by discrete Fourier transforms. Pegg and Barnett's finite phase formalism is a canonical example, and later work explicitly studies cyclic phase-shift operators as finite-dimensional evolution operators.

Schwinger/Weyl finite-state constructions represent cyclic state permutations by unitary shift operators whose eigenvalues are roots of unity, with conjugate phase/clock operators related through the discrete Fourier transform. Modern finite discrete phase-space treatments formulate the same structure on \(\mathbb Z_k\times\mathbb Z_k\).

These references validate the mathematical representation. They do not supply the EDF physical premise of coherent primitive timing; that premise belongs to EDF itself.
